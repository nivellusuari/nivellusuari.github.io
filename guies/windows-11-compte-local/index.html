Windows 11 tokiko kontuarekin instalatu eta debloat egin

Instalazioa, pribatutasuna eta beharrezkoa ez den softwarea kentzea

Hasi aurretik

Egin segurtasun-kopia bat, prestatu Microsoften USB instalatzaile ofiziala eta egiaztatu Windows 11ren eskakizunak. BitLocker erabiltzen baduzu, gorde berreskuratze-gakoa.

Tokiko kontuarekin instalatzea

Hasierako konfigurazioan (OOBE), bertsio batzuek Maius + F10 erabiliz kontsola ireki eta hurrengo komandoa probatzeko aukera ematen dute. Microsoft-ek bertsio berrietan blokeatu dezake; ez dago bermatuta. Huts egiten badu, begiratu zure bertsioaren aukera ofizialak.

OOBE\BYPASSNRO

Instalatu ondoren

Osatu Windows Update, egiaztatu kontrolatzaileak, konfiguratu hizkuntza eta berrikusi Ezarpenak → Pribatutasuna eta segurtasuna.

Win11Debloat erabiliz garbitzea

Deskargatu Win11Debloat Raphireren biltegi ofizialetik soilik, eta aztertu fitxategiak eta aukerak exekutatu aurretik. Saihestu irm | iex motako komandoekin urruneko kodea zuzenean exekutatzea.

Gomendatutako aukerak

Custom Setup atalean, aztertu aukerako telemetria, iragarkiak, gomendioak, Widgets, Bing integrazioa eta erabiltzen ez dituzun AA funtzioak. Mantendu Windows Update, Microsoft Defender, jakinarazpenak, kokapena behar baduzu, BitLocker, Storage Sense eta Xbox jolasten baduzu.

Aplikatu eta egiaztatu

Sortu leheneratze-puntu bat eta konfigurazioaren babeskopia, tresnak ahalbidetzen badu. Berrikusi aldaketak aplikatu aurretik; berrabiarazi Windows guztiz eta egiaztatu Hasi menua, bilaketa, eguneratzeak eta aplikazioak. Baliteke aldaketa batzuk itzulezinak izatea.

Oharra

Aukerak Windowsen eta Win11Debloat-en bertsioen arabera alda daitezke. Ez desgaitu segurtasun-babesak errendimendua itxuraz hobetzeko.
